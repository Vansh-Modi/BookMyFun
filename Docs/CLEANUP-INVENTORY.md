## Summary of Cleanup Decisions

1. **Items Removed**:
   - Runtime DDL execution in `Data/DatabaseInitializer.cs` (`InitializeAsync()` no longer executes runtime table creation or schema alteration).
   - "2-Day Advance Notice Required" always-visible banner (`#decorLeadTimeAlert`) from `Views/Booking/Checkout.cshtml`.
   - Duplicated normalization logic in `StayCelebrationEligibilityService.NormalizeArea` (now delegates to `EventManagerController.TryNormalizeArea`).
   - Unused using statements in cleaned files.

2. **Items Kept**:
   - `PropertyOccasions` table, repository mappings, and schema data (used for Owner property management).
   - `PropertyImages` table and schema data (kept for historical database compatibility).
   - `SecurityDepositAmount`, `Latitude`, and `Longitude` database columns and model bindings (active in financial, claim, and mapping features).
   - `checkDecorLeadTime()` function signature and invocations in `Views/Booking/Checkout.cshtml` (maintained for test contract integrity, sanitized to prevent unwanted client alerts).
   - `handleGalleryThumb404` in `Views/Properties/Details.cshtml` (actively used for 404 thumbnail recovery).
   - Migration scripts in `/db`, `/db/migrations`, and `tools/DbMigrate` (never deleted, preserved as single source of truth for DDL).

3. **Items Reported**:
   - Runtime DDL removed from `DatabaseInitializer.cs` in favor of declarative versioned migrations.
   - All three audited columns (`SecurityDepositAmount`, `Latitude`, `Longitude`) are confirmed actively referenced and preserved without changes.
